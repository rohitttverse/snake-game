# 🐍 Snake Game

Ek simple aur fun Snake game — pure HTML, CSS aur JavaScript mein bana hua. Koi framework nahi, bas ek file!

## 🎮 Kaise khela jaye

- **Arrow keys** ya **WASD** se snake ko chalao
- **Space** = Pause/Resume
- 🍎 Food khao → Score +10, speed badhti hai
- Deewar ya khud se takrao → Game Over!
- 📱 Mobile par: on-screen buttons ya swipe

## 🚀 Kaise chalaye

Bas `snake.html` kholo browser mein — bas itna hi!

## 🏆 Features

- Score aur Best score (localStorage mein save hota hai)
- Speed dheere-dheere badhti hai
- Responsive design
